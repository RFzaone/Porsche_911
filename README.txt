PORSCHE 911 — PULSE
===================

HOW TO OPEN
1. Extract the ZIP.
2. Double-click OPEN_WEBSITE.bat, or open index.html in Chrome/Edge.
3. Allow sound when you press Start engine or Hold to rev.

FEATURES
- Cinematic startup sequence
- Red / pink theme switch
- Hold-to-rev synthetic engine interaction
- Interactive engineering component map
- Animated rear-deck / engine reveal
- PCM infotainment interface demo
- Publicly documented automotive software process
- Mobile-first responsive layout and fade-in animations

IMPORTANT IMAGE NOTE
The site uses remote real press/editorial photographs so an internet connection is required for those photographs. Local fallback artwork is included so the layout still works offline.

ACCURACY NOTE
The current 911's public documentation identifies Porsche Communication Management (PCM), Porsche Connect, Apple CarPlay and Android Auto. Porsche publicly identifies Android Automotive OS for newer vehicle platforms such as the electric Macan; this site does not claim the 911 uses Android Automotive OS because Porsche has not publicly disclosed the complete underlying 911 OS stack.
